# AnonyMed

Local de-identification of patient documents (PDF, scans, photos) so that they can be handed to cloud language models for drafting letters. Identifiers come from a CardDAV address book (Nextcloud), are replaced by stable pseudonyms, and are re-inserted locally afterwards. The pseudonym key never leaves the machine.

Planned as a Python core with a command line and a desktop GUI for macOS, Windows and Linux. The design, open decisions and milestones are in [CLAUDE.md](CLAUDE.md) (German).

Status: planning, no code yet (30 October 2026). The project name is provisional; see the open decisions.
